# E-Commerce Sales Analytics | SQL & Power BI

## Project Overview

This project focuses on analyzing e-commerce business data using **MySQL and Power BI** to uncover meaningful insights into sales performance, customer behavior, product trends, order management, and business operations.

The project involved designing and developing a relational database in MySQL, populating it with structured data, performing SQL queries for data analysis, and connecting the database to Power BI to build an interactive dashboard for business decision-making.

## Tools & Technologies

- **MySQL** – Database creation, data management, SQL analysis, and joins.
- **Power BI** – Data visualization, dashboard development, and business reporting.
- **SQL** – Data retrieval, filtering, aggregation, joins, and analysis.
- **DAX** – Measures and calculations for dashboard KPIs.

## Database Structure

The database was designed using the following tables:

- Customers
- Addresses
- Categories
- Suppliers
- Products
- Orders
- Order_Details
- Payments
- Shipping

## Project Workflow

1. Designed and created a relational database using MySQL.
2. Created tables with primary keys and foreign key relationships.
3. Inserted and managed structured e-commerce datasets.
4. Performed data validation and record-count checks.
5. Wrote SQL queries using filtering, aggregation, joins, and other analytical techniques.
6. Connected MySQL data to Power BI.
7. Developed interactive dashboards and visualizations.
8. Analyzed sales, orders, products, and customer-related business metrics.
